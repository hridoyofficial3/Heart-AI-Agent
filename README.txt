Dipanwita Bot - native Android project (Chaquopy)
- Python code: app/src/main/python  (bot.py, engine.py, server.py, search.py, config.py, service.py)
- UI: app/src/main/assets/index.html (same chat UI)
- Build: GitHub Actions (.github/workflows/build.yml) -> Artifacts -> dipanwita-apk
- API keys: put in app/src/main/python/config.py or add in the app's API manager
